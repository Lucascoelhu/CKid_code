1 🤔 O que é programar?

Programar é dar ordens para o computador. O computador faz exatamente o que você mandar — nem mais, nem menos!

🍳 Pensa assim: é como uma receita de bolo. Você escreve os passos, e o computador segue um por um, na ordem certa.

No CKid, você escreve as ordens em português, usando comandos simples como mostrar e ler.

2 🖨️ Mostrando texto na tela

O comando mostrar exibe uma mensagem na tela do programa. Coloque o texto entre aspas "assim":

inicio mostrar("Olá, mundo!"); mostrar("Eu sei programar!"); fim

Cada mostrar aparece em uma linha diferente na saída. O ponto e vírgula ; no final é obrigatório — ele avisa que a ordem acabou!

💡 Dica: Você pode mostrar várias coisas de uma vez separando com vírgula:
mostrar("Meu nome é ", nome, "!");
3 📦 Variáveis — guardando informações

Uma variável é como uma caixinha com um nome. Você guarda um valor dentro dela e pode usar depois.

📦 Imagina: uma caixa chamada "idade" com o número 10 dentro. Sempre que você falar "idade", o computador pega o 10 da caixa!

No CKid existem 3 tipos de variável:

inicio int pontos, nivel; // dois inteiros, ambos começam em 0 real preco := 9.99; // números com vírgula (3.14, 9.99...) texto nome := "Ana"; // palavras e frases fim

O símbolo := significa "recebe". Leia como: "a variável pontos recebe o valor 0".

inicio int pontos := 0; pontos := pontos + 10; // soma 10 aos pontos mostrar("Pontos: ", pontos); // mostra: Pontos: 10 fim
4 ⌨️ Lendo o que o usuário digita

O comando ler pausa o programa e espera você digitar algo. O que você digitar fica guardado numa variável:

inicio texto nome := ""; mostrar("Qual é o seu nome?"); ler(nome); mostrar("Olá, ", nome, "! Seja bem-vindo!"); fim
💡 Ordem importa! Sempre declare a variável antes de usar o ler. E sempre use mostrar antes para avisar o usuário o que digitar!
5 ❓ Decisões com se...senão

O se faz o programa tomar uma decisão. Se a condição for verdadeira, executa um bloco; senão, executa outro:

🌧️ Na vida real: "SE estiver chovendo, pego o guarda-chuva. SENÃO, vou sem ele."
inicio int idade := 0; mostrar("Quantos anos você tem?"); ler(idade); se (idade >= 10) { mostrar("Você tem 10 anos ou mais!"); } senao { mostrar("Você tem menos de 10 anos!"); } fim

As chaves { } marcam o início e o fim de cada bloco de código. Tudo que estiver dentro delas pertence àquele bloco.

🔍 Operadores de comparação:
== igual a  |  != diferente de
> maior que  |  < menor que
>= maior ou igual  |  <= menor ou igual
6 🔄 Repetição com enquanto

O enquanto repete um bloco de código várias vezes, enquanto uma condição for verdadeira:

🎮 No jogo: "ENQUANTO o jogador tiver vidas, continue jogando."
inicio int x := 1; enquanto (x <= 5) { mostrar("Repetição número ", x); x := x + 1; // IMPORTANTE: avança x! } fim
⚠️ Cuidado! Sempre lembre de mudar a variável da condição dentro do loop. Se você esquecer o x := x + 1, o programa vai ficar repetindo para sempre!
7 🔂 Contando com para

O para é perfeito quando você sabe exatamente quantas vezes quer repetir. Ele tem 3 partes:

inicio // para (início; condição; passo) para (i := 1; i <= 5; i := i + 1) { mostrar("Número: ", i); } fim
📖 Leia assim: "Para i começando em 1, enquanto i for menor ou igual a 5, some 1 ao i a cada repetição."

1️⃣ início: i := 1 — começa aqui
2️⃣ condição: i <= 5 — para quando isso for falso
3️⃣ passo: i := i + 1 — o que muda a cada volta
8 🏆 Juntando tudo — seu primeiro jogo!

Agora que você conhece variáveis, se, ler e enquanto, dá para fazer um jogo de adivinhação!

inicio int secreto := 7; // número a adivinhar int chute := 0; // palpite do jogador mostrar("Adivinhe de 1 a 10!"); enquanto (chute != secreto) { ler(chute); se (chute > secreto) { mostrar("Muito alto! Tente menos."); } senao { se (chute < secreto) { mostrar("Muito baixo! Tente mais."); } } } mostrar("🎉 Acertou!"); fim
🚀 Próximos passos: Tente modificar o número secreto, ou adicionar um contador de tentativas. A programação é sobre experimentar!

📋 Arrays (vetores)

int  notas[5];          // array de 5 inteiros
real precos[10];        // array de 10 decimais
texto nomes[3];         // array de 3 textos

notas[0] := 10;        // atribui valor (índice começa em 0)
mostrar(notas[0]);     // acessa valor
ler(notas[1]);         // lê valor do teclado

// Percorrer com para:
int i;
para (i := 0; i < tamanho(notas); i := i + 1) {
  mostrar(notas[i]);
}

tamanho(notas)         // retorna o tamanho do array

🔄 enquanto

enquanto (x < 10) {
  mostrar(x);
  x = x + 1;
}

🔁 faça...enquanto

faca {
  mostrar("Oi!");
  x = x + 1;
} enquanto (x < 3);

🔂 para

para (i = 1; i <= 5; i = i + 1) {
  mostrar(i);
}
